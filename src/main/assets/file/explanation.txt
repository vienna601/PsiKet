Important notes before we start~
<html><div style="width: 400px;">Grover’s algorithm solves the problem of finding a marked item in an unsorted list. Classically, this takes on average N/2 checks. Grover’s algorithm provides a quadric speedup.<br>A qubit is described by amplitudes 𝛼 and 𝛽: ∣ψ⟩ = α∣0⟩+β∣1⟩. The probability of measuring a state is the square of its amplitude’s magnitude.<br>Superposition does not mean the computer tries all answers at once. It just means all possible answers are represented as amplitudes that can interfere.<br>Changing a state’s phase does not change its measurement probability.<br>However, phase changes affect how amplitudes interfere in later steps when measuring.</div></html>~
Step 1: Ensuring Equal Superposition~
<html><div style="width: 400px;">Imagine a 3D vector with equal weights on all components. Our goal is to force this vector to eventually point to the answer, in this case,∣2⟩.The superposed vector really only moves in the 2D plane spanned by these vectors.<br>Let's say the y axis is our answer and the x axis is the balance of all other states, in this case,∣+⟩. The superposed vector has a component in the target direction.</div></html>~
Step 2: Finding the angle~
<html><div style="width: 400px;">As the number of dimensions increase, our superposed vector becomes closer to being perpendicular with our target vector. But since it contains a component of our target, the angle between them never reaches 90 degrees. To find this angle, we take the dot product between the balanced state and the target, which results in 1/sqrtN. This is the cosine of the angle between the vectors, which equals the sine of the complimentary angle. For tiny angles, the angle is approximately equal to the sine, so long as they are measured in radians.</div></html>~
Step 3: Phase Flip~
<html><div style="width: 400px;">Just like with classical logic gates like AND, OR, NOT, we can manipulate quantum gates so that the correct state gets a phase flip. Note that this will not directly reveal the answer to us, but we can use this with another operation to significantly increase the chances of measuring it. This collection of operations is abstracted away, and we call this black box as the oracle.</div></html>~
Step 4: Amplifying the target component~
<html><div style="width: 400px;">By first flipping about the x axis, then flipping about the balanced vector, the new vector points slightly more in the vertical direction. We repeat this process until the resulting vector gets as close as it can to our target.<div></html>~
Step 5: Number of repetitions~
<html><div style="width: 400px;">Finally, we just need to figure out the number of repetitions needed. In geometry, if we flip about two lines, the overall effect is a rotation by 2 times the angle between them. In our case, we want to rotate the vector approximately pi/2 radians. Therefore, the number of operations is pi/4 times sqrtN. This is what gives us the quadratic speedup.</div></html>
